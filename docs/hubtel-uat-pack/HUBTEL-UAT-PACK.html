1. End-user UAT meeting

  1. Open https://ipaysub.vercel.app/portal/renew
  2. Enter PPPoE username → look up account (package, amount, expiry)
  3. Proceed to checkout → complete payment in Hubtel modal
  4. Confirm service extended on merchant side

2. Integration flow

Customer → iPay API (quote + unique clientReference)
        → Hubtel CheckoutSdk.openModal(purchaseInfo, config)
        → Customer pays
        → Hubtel callback → iPay /api/payments/hubtel/callback
        → Fulfill PPPoE / voucher
        → (fallback) Hubtel Transaction Status Check
